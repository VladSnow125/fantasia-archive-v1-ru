## 0.1.14

### Важное, очень печальное объявление
- GitHub Actions (компилятор для нескольких операционных систем, которым я пользуюсь) перестал поддерживать нашу версию MacOS (MacOS11), и поэтому я больше не смогу автоматически собирать сборки для Mac в FA1 (в новой версии этой проблемы не будет). Возможно, это ещё можно исправить, если кто-то соберёт FA на собственном Mac или если кто-нибудь из сообщества с Mac откликнется и сумеет собрать для вас новейшую версию FA, но на данный момент я, к сожалению, вынужден отказаться от прямой поддержки любых новых готовых сборок для Mac.
- Эту проблему, возможно, удастся временно решить благодаря моему дорогому другу, который предложил для компиляции Mac до серии M — по крайней мере на время. Это не постоянное решение, но на момент написания этого текста оно должно хотя бы работать для текущей версии (0.1.14).
