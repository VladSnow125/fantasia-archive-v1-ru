
- Примечания по типам фильтров
  - Пробелы заменяются символом `-`
  - Префикс `@` включает в поиск поле `Другие имена`
- Типы фильтров
  - `$` — тип документа
  - `#` — тег
  - `>` — иерархический путь
  - `^` — переключатель
    - `^c` — является категорией
    - `^d` — мёртв/пропал/уничтожен
    - `^f` — завершён
    - `^m` — второстепенный документ
- Полнотекстовый поиск
  - `%` — начало полнотекстового поиска
  - `:` — разделитель между именем поля и значением поля
  - `%some-field:some-value` — поиск значения по всем полям
  - Так же можно искать по цветам: `%color:blue`
  - Обёртка `""` для точного поиска (имени поля и/или значения)
    - Пример: `%"some-field":"some-value"`
